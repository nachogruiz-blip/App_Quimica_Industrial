# Derechos de autor y materiales

- Los PDFs de clase (apuntes y relaciones de ejercicios) pueden tener derechos de autor:
  **nunca se suben a este repositorio**, que se trata como público (puede volver a abrirse). `.gitignore` excluye `materiales/` y `*.pdf`.
- Están en el repo **privado** `App_Quimica_Industrial_materials` (raíz, nombres originales).
- Todo lo que hay en `datos/` es elaboración propia: explicar con otras palabras, preguntas nuevas, problemas con
  datos aleatorios «del mismo tipo» que los de clase (no copiar enunciados literales). No copiar figuras.
- Datos técnicos y constantes físicas (rugosidades, viscosidades, conversiones) sí pueden usarse.
