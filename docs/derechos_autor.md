# Derechos de autor y materiales

- Los PDFs del centro/libros pueden tener derechos de autor: **nunca se suben a este repositorio** (que puede ser
  público para usar GitHub Pages). `.gitignore` excluye `materiales/` y `*.pdf`.
- Todo lo que hay en `datos/` es elaboración propia: resumir y explicar con otras palabras, preguntas nuevas.
  No copiar párrafos, tablas completas ni figuras. Datos y constantes físicas sí pueden usarse.
- **Dónde guardar los PDFs**: en un repositorio **privado** aparte, `App_Quimica_Industrial_materiales`
  (si existe), con los PDFs en la raíz o por UD. Un agente nuevo lo clona en `materiales/` para trabajar:
  `git clone https://github.com/nachogruiz-blip/App_Quimica_Industrial_materiales materiales`
